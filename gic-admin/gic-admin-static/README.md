# GIC Admin Static Pages

Desktop-first React/Vite static implementation based on the supplied GIC admin reference.

## Main screens
- Dashboard
- Members
- Events
- Event detail
- Messages
- Message detail
- Settings
- Nested placeholders for Registrations, Forms, Scheduled Messages, Users & Roles, Notification Settings, Reports and Activity Log

## Run
npm install
npm run dev

## Production
npm run build

The project is frontend-only. Replace the demo arrays with the API/database layer later. The Vite output is `dist`, suitable for a Render Static Site.
