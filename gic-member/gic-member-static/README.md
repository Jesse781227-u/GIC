# GIC Member Static Pages

Static React/Vite implementation of the 21 member screens in the supplied reference image.

## Run

```bash
npm install
npm run dev
```

Then open the Vite URL.

## Included screens/routes

1. `/` — Welcome
2. `/onboarding/create-account`
3. `/onboarding/verify`
4. `/onboarding/profile`
5. `/onboarding/ministries`
6. `/onboarding/notifications`
7. `/onboarding/complete`
8. `/home` — Dashboard
9. `/announcements/1`
10. `/events`
11. `/events/youth-conference-2024`
12. `/events/youth-conference-2024/register`
13. `/events/youth-conference-2024/success`
14. `/forms`
15. `/forms/prayer-request`
16. `/ministries`
17. `/ministries/youth`
18. `/notifications`
19. `/notifications/1`
20. `/profile`
21. `/profile/edit`

Additional static routes included for sign-in and registrations.

This is intentionally frontend-only. Data, authentication, push notifications, registration persistence, and APIs are not connected yet.
